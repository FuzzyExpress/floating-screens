## Mirror small computer screens to big screens with VR

Ever try using a small tablet or laptop on a short table?
It's very uncomfortable. 

Floating Screens is a solution for this problem on Linux.

This will stream an HEVC video stream to this app running on a Meta Quest.

Pass through and hand tracking support.
